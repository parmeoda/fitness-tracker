# Lab: Fitness Tracker

## Project Description

This program lets the user enter their workout type, duration, and distance. It uses inheritance to show the workout information and calculates how many calories were burned.

## How to Run

1. Open the Java project in IntelliJ.
2. Open Main.java.
3. Run Main.java.
4. Enter the workout type, duration, and distance when asked.
5. The program will show the workout information and calories burned.

## Example Output

```text
Enter workout type: Morning Run
Enter duration (minutes): 45
Enter distance (km): 6.5
--- Workout Summary ---
Workout: Morning Run
Duration: 45 minutes
Distance: 6.5 km
Calories burned: 390.0
```
This program lets the user enter their workout type, duration, and distance. It then shows the workout information and calculates how many calories were burned.
